# Telegram-бот CaseNova

Бот показывает три кейса с настраиваемыми шансами наград, ведёт виртуальный
баланс и сохраняет историю открытий в локальной базе SQLite. Новому пользователю
автоматически начисляется 5000 виртуальных ⭐.
Пользователи могут приглашать друзей по личной ссылке: за каждого нового
пользователя, который впервые запускает бота по ссылке, пригласившему начисляется
500 виртуальных ⭐.

Виртуальные игровые ⭐ — отдельные баллы CaseNova, а Telegram Stars (XTR) —
отдельная валюта оплаты Telegram. Покупка цифрового значка не меняет игровой
баланс. В магазине нет физических призов, ставок или платных случайных розыгрышей.

Архитектура платежей Telegram Stars добавлена, но покупки выключены по умолчанию.
В рабочем режиме доступен только фиксированный цифровой значок профиля; выдача
происходит лишь после подтверждённого `successful_payment`.

## Запуск

Токен хранится в секрете Replit `TELEGRAM_BOT_TOKEN`. Не добавляйте его в файлы
проекта и не отправляйте в чат. Запустите рабочий процесс **Telegram Bot**.

Локально из корневой папки проекта:

```sh
export TELEGRAM_BOT_TOKEN="токен-бота"
python3 telegram_bot/bot.py
```

## Баланс и история

При первом сообщении пользователя бот создаёт для него баланс в 5000 виртуальных
⭐. Покупка кейса, случайный выбор награды, зачисление выигрыша и запись истории
выполняются одной транзакцией SQLite. Повторная обработка того же нажатия не
списывает баланс и не начисляет награду повторно.

База `telegram_bot/casenova.sqlite3` создаётся автоматически и сохраняется между
перезапусками рабочего процесса. Файл базы и журналы SQLite исключены из Git.

## Настройка кейсов

Цены, возможные виртуальные награды и вероятности находятся в
`telegram_bot/case_config.py`. Сумма вероятностей для каждого кейса должна быть
равна 100%.

Размер бонуса за приглашение настраивается в `telegram_bot/referral_config.py`.
Число приглашённых и сумма начисленных бонусов сохраняются в той же базе SQLite.

## Telegram Stars и безопасный режим

Чтобы подготовить конфигурацию в Replit Secrets, используйте:

- `TELEGRAM_PAYMENTS_ENABLED=false` — безопасное значение по умолчанию. Не меняйте
  на `true`, пока не проверены все остальные настройки.
- `TELEGRAM_ADMIN_IDS` — один или несколько числовых Telegram user ID через запятую.
- `TELEGRAM_PROFILE_BADGE_PRICE_XTR` — положительная целая цена значка в Telegram Stars.
- `TELEGRAM_TERMS_VERSION=v1` — текущая версия условий; изменяйте её при обновлении условий.
- `TELEGRAM_PAYMENT_SUPPORT_USERNAME` — публичное имя поддержки без `@`.

`TELEGRAM_BOT_TOKEN` остаётся без изменений. Для Telegram Stars не нужен платёжный
`provider_token`: Bot API получает пустое значение только для счёта в `XTR`.
Никакая часть покупки не пополняет виртуальный баланс и не открывает кейсы.

Пользователь открывает `/terms`, принимает текущую версию условий, затем выбирает
**🛍 Покупки** или `/shop`. Бот создаёт уникальный заказ и счёт на один фиксированный
товар. Telegram проверяет его через `pre_checkout_query`; цифровой значок выдаётся
только после `successful_payment`. Администратор с ID из `TELEGRAM_ADMIN_IDS`
смотрит заказы через `/admin` и может запросить возврат командой
`/refund <ID заказа или Telegram charge ID>`. Пользователь получает помощь через
`/paysupport`.

Автоматические тесты используют подмену Telegram API и не списывают Stars. Если
включить платежи на настоящем боте, покупка будет реальной и спишет Telegram Stars.
Оставляйте `TELEGRAM_PAYMENTS_ENABLED=false`, пока цена, администраторы, поддержка
и условия не проверены.
